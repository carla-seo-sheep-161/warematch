# Judged rubric (score 0-5, one line of evidence per score; quote the page)
1. **Intent fit**: What is the dominant intent in the SERP (informational / transactional / navigational; listicle / guide / tool / landing page)? Does the page do that job in its first screen? Are the top query clusters answered (see audit.py coverage)? 5 = a searcher could finish their task here; 1 = answers a different question.
2. **Decision utility**: Could a reader choose or act differently after reading? Look for thresholds, if/then rules, red flags, worked examples with stated assumptions. 1 = generic checklist ("ask about X").
3. **Information gain vs the SERP**: List what the top-ranking pages cover that this page lacks, and what this page has that none of them do. 5 = a real, cited, local or practitioner insight competitors lack; 1 = a re-statement.
4. **Specificity / expertise**: Interchangeability test: replace the product/location name; does the section still read the same? If yes, it is interchangeable. Count named rules, regulations, datasets, figures with period, conditions.
5. **GEO extractability**: answer-first openings (40-80 words) under question-style headings, one-sentence definitions of terms, self-contained passages (no "this/it" openers), figures with publisher + period in the same sentence, consistent entity naming, quotes attributed to a named person, FAQ visible in the page (for FAQPage), steps visible (for HowTo), listings visible in HTML (for ItemList). Is it in raw HTML without JS?
6. **Trust**: primary sources only, dated, hedged where the source is narrow (e.g. one state's opinion), no unsourced marketing claims (check locked/template copy separately and flag).
7. **Locality fit** (location pages): swap test. Replace the place name; list which facts would change. If almost none, the page is boilerplate. Check the fallback chain (city to county/region to state to country) is not hiding generic text.
8. **House rules**: template lock, no emoji, links rules, promo bias (blogs), meta rules (title <=65, description <=160, "3PL" not "third-party logistics", brand suffix, CTA), no competitor names, no rankings.
Output: table of scores + evidence; "interchangeable sections" list; top-5 fixes with data needed; decisions for the owner.
